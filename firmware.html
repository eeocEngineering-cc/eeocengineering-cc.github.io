Firmware Update

Before you start:
This tool flashes firmware directly from your browser over USB — no software install needed. It requires a desktop browser with Web Serial support: Google Chrome, Microsoft Edge, or Opera. It will not work in Safari or Firefox, and it does not work on mobile.
Your current browser doesn't support the Web Serial API, so this tool can't run here. Please open this page in Chrome, Edge, or Opera on a desktop computer.
